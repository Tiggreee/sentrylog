# sentrylog

Real-time security monitoring dashboard for CCTV events, vehicle recognition, and alert workflows.

## Stack

- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL

## Repository Structure

- `client/` frontend application
- `server/` backend API and integration layer

## Quickstart

```bash
# client
cd client
npm install
npm run dev

# server
cd ../server
npm install
npm run dev
```

## Scope

sentrylog focuses on operational observability, alerting integrity, and traceable security events.
